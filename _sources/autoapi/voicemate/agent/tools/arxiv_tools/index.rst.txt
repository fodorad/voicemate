voicemate.agent.tools.arxiv_tools
=================================

.. py:module:: voicemate.agent.tools.arxiv_tools

.. autoapi-nested-parse::

   arXiv search and paper download.

   Downloaded papers are saved as PDFs under ``[files] papers_dir`` (default
   ``~/Downloads/voicemate-papers``) so Adam can open them, and their text is indexed into
   research memory so later questions are answered without re-downloading.

.. py:class:: Paper

   arXiv metadata.

   :ivar arxiv_id: Short id such as ``2401.01234v2``.
   :ivar title: Paper title.
   :ivar authors: Author names (first few).
   :ivar published: Publication date ``YYYY-MM-DD``.
   :ivar summary: Abstract.
   :ivar pdf_url: Direct PDF link.
