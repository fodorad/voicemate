voicemate.config
================

.. py:module:: voicemate.config

.. autoapi-nested-parse::

   Typed application configuration loaded from ``config/voicemate.toml``.

   Every section of the TOML file maps onto one dataclass below. Missing keys fall back to
   the dataclass defaults; unknown keys raise :class:`ValueError` so typos never pass silently.

.. py:class:: LLMConfig

   Ollama chat model settings.

   Each profile is one Ollama model used for everything (chat, tools, memory decisions).

   :ivar profile: Preferred profile name.
   :ivar profiles: Profile name → Ollama model tag.
   :ivar fallback_profile: Profile used when the preferred one is missing or does not fit.
   :ivar memory_guard: Check free memory at startup before choosing the model.
   :ivar reserve_gb: Memory kept free for the speech stack, the UI process and the OS (GB).
   :ivar temperature: Sampling temperature.
   :ivar num_ctx: Context window requested from Ollama.
   :ivar keep_alive: How long Ollama keeps the model loaded after the last request.
   :ivar max_tool_rounds: Maximum agent ⇄ tool iterations per turn.
   :ivar turn_timeout_s: Hard limit for one conversational turn.



   .. py:attribute:: profile

.. py:class:: UIConfig

   Web UI server.

   :ivar host: Interface to bind; keep ``127.0.0.1`` for a private assistant.
   :ivar port: HTTP port.
   :ivar allowed_hosts: Accepted ``Host`` headers; anything else is rejected, which blocks DNS
                        rebinding (a web page reaching the local assistant through a hostile domain).
   :ivar test_audio: Allow ``?fake_mic=<file>`` to play a WAV from ``data/fake_mic`` as if it
                     were spoken (for automated end-to-end tests only).



   .. py:attribute:: host

.. py:function:: load_config(path: pathlib.Path | None = None, env: collections.abc.Mapping[str, str] | None = None, default_path: pathlib.Path = DEFAULT_CONFIG_PATH) -> Config

   Load the configuration file.

   :param path: Explicit TOML file. When omitted, ``$VOICEMATE_CONFIG`` or ``default_path`` is
                used; if the default file does not exist (installed package), the built-in
                defaults apply.
   :param env: Environment mapping (defaults to :data:`os.environ`).
   :param default_path: The repository's configuration file.

   :returns: The parsed configuration.

   :raises ValueError: If the file contains unknown keys.
   :raises FileNotFoundError: If an explicitly named file does not exist.
