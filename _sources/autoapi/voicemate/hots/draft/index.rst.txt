.. py:class:: Draft

   One draft in progress.

   :ivar enemy: Hero slugs the enemy picked, in pick order.
   :ivar ally: Hero slugs on Adam's team, in pick order.
   :ivar banned: Hero slugs already banned (by either side).
   :ivar map_slug: The map being played, if known.



   .. py:attribute:: enemy
      :type:  list[str]
      :value: []



   .. py:attribute:: ally
      :type:  list[str]
      :value: []



   .. py:attribute:: banned
      :type:  list[str]
      :value: []



   .. py:attribute:: map_slug
      :type:  str | None
      :value: None



   .. py:method:: side(name: str) -> list[str]

      The list for ``enemy``, ``ally`` or ``banned``.



   .. py:method:: add(name: str, heroes: list[str]) -> None

      Add heroes to a side (heroes already there are kept once).



   .. py:method:: remove(name: str, heroes: list[str]) -> list[str]

      Remove heroes from a side; returns the ones that were actually there.



   .. py:method:: reset() -> None

      Start a new draft.
