voicemate.hots.screen.watcher
=============================

.. py:module:: voicemate.hots.screen.watcher

.. autoapi-nested-parse::

   Draft mode: watches the screen and keeps the draft up to date.

   The watcher looks at the screen only while Adam has switched game mode on (:meth:`start`); a
   command that asks for a read is the only other time the screen is captured. While no draft is
   on screen it takes a quick, rough look every few seconds. When a ban or pick screen appears it
   starts a draft: the draft state is reset, a screen log folder is opened and from then on every
   look is a full read that adds what the screen shows (locked heroes, bans, the map) to the
   :class:`~voicemate.hots.draft.Draft`. "MATCH STARTING" ends the draft; the watcher then stays
   quiet until the next draft screen shows up.

.. py:class:: DraftWatcher(reader: voicemate.hots.screen.reader.ScreenReader, roster: voicemate.hots.roster.Roster, maps: collections.abc.Mapping[str, str], draft: voicemate.hots.draft.Draft, portraits: voicemate.hots.screen.interpreter.BanReader | None = None, log: voicemate.hots.screen.log.ScreenLog | None = None, poll_s: float = 2.0, proactive: bool = False, sleep: collections.abc.Callable[[float], collections.abc.Awaitable[None]] = asyncio.sleep, monotonic: collections.abc.Callable[[], float] = time.monotonic)

   Follows the draft on screen (a :class:`~voicemate.pipeline.skills.Background` worker).

   :param reader: Looks at the screen.
   :param roster: Resolves hero names.
   :param maps: ``slug → name`` of the maps.
   :param draft: The session's draft, kept current while a draft is on screen.
   :param portraits: Reads the ban slots.
   :param log: Where captured screens are saved (not saved when omitted).
   :param poll_s: Seconds between looks.
   :param proactive: Say "Your ban." / "Your pick." when it becomes Adam's turn.
   :param sleep: Waits between looks (replaceable for tests).
   :param monotonic: Clock for the age of a read (replaceable for tests).
