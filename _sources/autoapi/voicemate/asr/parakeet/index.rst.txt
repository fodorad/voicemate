.. py:class:: ParakeetRecognizer(model: str = DEFAULT_MODEL, device: str = 'cpu')

   Speech recognizer backed by ``parakeet-mlx``.

   MLX computations must stay on one thread, so call :meth:`transcribe_text` from a single
   worker thread (the voice session uses a dedicated executor).

   :param model: Hugging Face repository of the MLX checkpoint.
   :param device: ``"cpu"`` or ``"gpu"``. CPU is the default because the GPU is shared with
                  the LLM (about 280 ms instead of 160 ms for a 4 s utterance).


   .. py:method:: transcribe_text(audio: numpy.ndarray) -> str

      Transcribe 16 kHz mono float32 audio.

      :param audio: Samples in ``[-1, 1]``.

      :returns: The transcript (empty for silence or too-short input).
