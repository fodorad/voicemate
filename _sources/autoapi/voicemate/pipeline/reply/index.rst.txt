voicemate.pipeline.reply
========================

.. py:module:: voicemate.pipeline.reply

.. autoapi-nested-parse::

   The reply of one turn: what is said, when, and how long it took.

   A :class:`Reply` is created for each turn. The session feeds it the streamed answer text and the
   agent's tool events; it decides what becomes speech (complete sentences, a spoken filler while
   a network tool runs, an apology when the turn fails), remembers the answer text (so an
   interrupted reply can be kept in the history) and the timings, and builds the turn's metrics.
   Cancelling, the timeout, the speech worker and publishing events stay with the session.

.. py:class:: Reply(lang: str, ended_at: float, clock: collections.abc.Callable[[], float] = time.monotonic)

   State and rules of one turn's answer.

   :param lang: Reply language of the turn.
   :param ended_at: Monotonic time the user finished (reference for the timings).
   :param clock: Monotonic time source (injectable for tests).

   :ivar text: The answer written so far.
   :ivar spoke: Something was queued for speech.
   :ivar failed: The turn failed.
   :ivar tools: Names of the tools the agent started.
   :ivar first_token: Monotonic time of the first token or tool start, if any.
   :ivar first_audio: Monotonic time the first audio was ready, if any.
   :ivar queue: Speech to synthesize, in order; ``None`` marks the end.
