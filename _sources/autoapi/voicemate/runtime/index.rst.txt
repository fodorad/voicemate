.. py:data:: logger

.. py:function:: use_offline_hub_if_cached(repos: list[str]) -> bool

   Switch Hugging Face Hub to offline mode when every repository is already cached.

   Loading a cached model still sends metadata requests to huggingface.co; for a private
   assistant nothing but explicit tool calls should leave the machine.

   :returns: True when offline mode was enabled.


.. py:class:: Runtime

   Shared components.

   :ivar config: Application configuration.
   :ivar recognizer: Speech recognizer (``None`` for text-only use).
   :ivar voices: TTS voices (``None`` for text-only use).
   :ivar vad_factory: Creates a fresh VAD model per session (VAD is stateful).
   :ivar graph: Compiled LangGraph agent.
   :ivar model_choice: The chat model chosen by the memory guard (None in tests).
   :ivar memory: Long-term memory store.
   :ivar notes: Notes database.
   :ivar langid: Language detector.
   :ivar asr_executor: Single worker thread for ASR (MLX is not re-entrant).
   :ivar tts_executor: Single worker thread for TTS.
