A rough sound-alike key: the consonant skeleton of how text is pronounced.

Kszalatat and Xal'atath both become kslt, so a badly pronounced name still lands next to the right hero.

resolve(text: str, available: collections.abc.Collection[str] | None = None) → Resolved[source]¶

Find the hero text names.

An exact (normalized) name, slug or alias wins; so does the start of exactly one name (mura); otherwise the best match by spelling and sound counts when it clearly beats every other hero. Anything else returns the closest candidates.

Parameters:

  • text – The typed or recognized name.

  • available – Slugs of the heroes that can still be meant; the start-of-name and sound-alike matches look only at these (an exact name always wins).
