voicemate.events¶

Events flowing from the voice pipeline to the UI, and a small asyncio pub/sub bus.

The UI renders one lane per pipeline stage. Several lanes can be active at the same time (the LLM keeps generating while earlier sentences are synthesized and spoken), so the status model is per lane rather than a single exclusive state.
